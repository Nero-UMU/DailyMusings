## 复现构建

Android APK（需要 `maui-android` 工作负载与 Android SDK；必须是 Release，Debug 版依赖 Fast Deployment，单独安装会以「No assemblies found」启动失败）：

```bash
dotnet build src/DailyMusings.Client -f net10.0-android -c Release -t:SignAndroidPackage
# 产物：src/DailyMusings.Client/bin/Release/net10.0-android/dev.dailymusings.client-Signed.apk
```

Windows 免安装包（自包含，解压即用；含 .NET 与 Windows App SDK 运行时，因此包体较大）：

```powershell
dotnet publish src\DailyMusings.Client -f net10.0-windows10.0.19041.0 -c Release `
  -p:WindowsPackageType=None -p:SelfContained=true -p:UseMonoRuntime=false `
  -p:WindowsAppSDKSelfContained=true -p:RuntimeIdentifier=win-x64 -o artifacts\windows
Compress-Archive -Path artifacts\windows\* -DestinationPath artifacts\release\DailyMusings-client-1.0.0-win-x64.zip -CompressionLevel Optimal
```

`UseMonoRuntime=false` 不是可选项：`SelfContained=true` 会沿着 MAUI 的默认值去还原 `Microsoft.NETCore.App.Runtime.Mono.win-x64`，而该运行时包并不存在，还原会直接失败。

## 曾经的 MSIX 路径（不再交付，留档备查）

1.0.0 曾构建、签名并成功安装过 MSIX（自签名证书 `CN=DailyMusings`，指纹 `C7FD833B2A89492BC613F91B1556E1A32334D4DE`，有效期至 2027-09-16）。按 A.16 定案，它不再是交付物，也不随版本复验。留档是因为这条路上有两个只有真装一次才会暴露的坑：

- **清单里的图片路径必须是 `$placeholder$.png`**。手写的 `Package.appxmanifest` 用老式模板的 `Assets\Square150x150Logo.png` 这类路径时，MAUI 的 `GeneratePackageAppxManifest` 不会替换它，而包实际生成的是 `appiconStoreLogo.png` / `splashSplashScreen.png` 这一组文件，于是 `Add-AppxPackage` 以 `0x80070003`「找不到初始屏幕图像 [SplashScreen.png]」拒绝注册。只做「能构建、能签名」的检查看不出这个问题。
- **自签名证书要进本机存储**，且**打包目标只在给了证书文件时才自动签名**：只传 `PackageCertificateThumbprint` 会静默产出未签名的包；`Get-AuthenticodeSignature` 也看不懂 AppX 容器（要看包内有没有 `AppxSignature.p7x`，或 `signtool verify /pa` 是否 `Successfully verified`）。

若将来确实需要 MSIX，构建命令是：

```powershell
dotnet publish src\DailyMusings.Client -f net10.0-windows10.0.19041.0 -c Release `
  -p:WindowsPackageType=MSIX -p:GenerateAppxPackageOnBuild=true `
  -p:AppxPackageSigningEnabled=true -p:PackageCertificateThumbprint=<指纹> `
  -p:SignAppxPackageExeFullPath="<signtool.exe 全路径>"
# 装之前（需要一次管理员 UAC）：
#   certutil -addstore -f TrustedPeople .\DailyMusings-client.cer
#   certutil -addstore -f Root        .\DailyMusings-client.cer
#   Add-AppxPackage .\DailyMusings.Client_1.0.0.0_x64.msix
```

## 客户端安装说明

- **Android**：Android 8.0（API 26）及以上。安装 APK 后首次进入设置页填入服务端地址，再用管理页签发的十分钟一次性配对码完成配对。录音权限在第一次按下录音按钮时申请。APK 是自签名的 debug 式签名包（未上架），安装时系统会提示「未知来源」，需要手动允许。
- **Windows**：Windows 10 1809（10.0.17763）及以上，x64。把 `DailyMusings-client-1.0.0-win-x64.zip` **解压到任意可写目录**，双击 `DailyMusings.Client.exe` 即可，无需安装、无需管理员权限、无需 .NET 运行时（包内自带）。想「固定到任务栏/开始屏幕」就在解压出的 exe 上右键选择即可。首次进入设置页填服务端地址并配对；录音需要「麦克风」权限，Windows 会在第一次录音时询问。

操作步骤见 [`使用手册.md`](使用手册.md)。
