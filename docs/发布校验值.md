## 复现构建

Android APK（需要 `maui-android` 工作负载与 Android SDK；必须是 Release，Debug 版依赖 Fast Deployment，单独安装会以「No assemblies found」启动失败）：

```bash
dotnet workload install maui-android
dotnet build src/DailyMusings.Client -f net10.0-android -c Release -t:SignAndroidPackage
# 产物：src/DailyMusings.Client/bin/Release/net10.0-android/dev.dailymusings.client-Signed.apk
```

## 客户端安装说明

- **Android**：Android 8.0（API 26）及以上。安装 APK 后首次进入设置页填入服务端地址，再用管理页签发的十分钟一次性配对码完成配对。录音权限在第一次按下录音按钮时申请。APK 是自签名的 debug 式签名包（未上架），安装时系统会提示「未知来源」，需要手动允许。

操作步骤见 [`使用手册.md`](使用手册.md)。
