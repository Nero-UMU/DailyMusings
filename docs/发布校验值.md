# 发布校验值

本文记录构建产物的 SHA-256，供下载后核对（§18 阶段五要求「生成 Android APK 和发布校验值」）。

**交付形态（2026-09-29 起）**：对外是**一份 compose 文件 + 一个 APK**（附录 A.26）。APK 与多架构服务端镜像都由 CI 在打 tag 时构建：

- 镜像：`ghcr.io/nero-umu/dailymusings`（`linux/amd64`、`linux/arm64`），同时给出语义化版本与 `latest`。
- APK：附在 [Releases](https://github.com/Nero-UMU/DailyMusings/releases) 里，**同页给出该次构建的 SHA-256**（`*.apk.sha256`），因此校验值以 Release 页为准，不再手工维护在下表——下表保留的是本轮之前手工构建并验证过的产物。

流程定义见 [`.github/workflows/release.yml`](../.github/workflows/release.yml)：`image` 作业构建推送镜像，`apk` 作业构建签名 APK，`compose-smoke` 作业**用仓库根那份 `compose.yaml` 真的起一次实例**（零配置一次、绑定挂载一次），`release` 作业把 APK 与校验值附到 Release。

**客户端形态（2026-09-24 起）**：只有 **Android APK**。电脑端客户端整体退出了项目方向（[`docs/开发指导.md`](开发指导.md) 附录 A.17），因此不再有 Windows 免安装包，也不再有任何 MSIX 相关产物与构建路径。
